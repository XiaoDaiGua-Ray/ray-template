Application `axios/utils` contains compatibility re-exports. The default request signal is injected only if the caller has not supplied a signal and has not disabled default cancellation. Demo data does not represent production endpoints or authorization. Frontend `VITE_*` configuration must not hold secrets.

Targeted verification: `pnpm harness verify api` first runs `api:check` for generated OpenAPI files and the MSW worker, then the [application request](../../__test__/axios/request.spec.ts), [client isolation](../../__test__/workspace/http-client.spec.ts), and [mock](../../__test__/mock/database.spec.ts) regressions. Verify production backend integration, browser downloads, and real end-to-end flows separately when those behaviors are affected.

For standard backend integration, start with the [shared contract package](../../packages/api-contracts/README.md), [business schemas](../../packages/api-contracts/src/admin.ts), [demo schemas](../../packages/api-contracts/src/demo.ts), [OpenAPI generation](../../packages/api-contracts/src/openapi.ts), and [integration guide](../../apps/docs/guide/backend.md). Pages call APIs exclusively, including for search options and route-example lists/details. The mock database owns demo writes and permission checks. In production backend mode, a remote-route load failure aborts startup. Legacy application contract paths remain as compatibility re-exports.
