Lightweight examples use public shared-package entry points. Examples needing application context use the restricted routes and in-memory cache in `example.html`. Display the same source that actually runs. For public contract changes, return to the owning topic and update guides, examples, and migration notes.

Targeted verification: `pnpm harness verify docs` runs `docs:check`, covering types, internal links, and the production build. Wording-only corrections can use source review and formatting checks. Use a browser only for affected rendering or interactions, selecting the relevant page/example and dimensions through the [documentation workflow](../../docs/docs-handoff.md#update-workflow). For admin embedding, deployment subpaths, or combined redirect artifacts, generate the combined output with `pnpm pages:build` and preview it as described in the [README](../../apps/docs/README.md).
