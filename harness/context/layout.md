The layout package owns the shell and rendering; the application supplies navigation, settings, content, and runtime state. Access application stores through [hooks](../../apps/admin/src/store/hooks). See the [store conventions](../../apps/admin/src/store/README.md) for persistence scope and historical formats. Preference files contain layout settings only; route sources and route JSON belong to [routing](routing.md).

Targeted verification: `pnpm harness verify layout`, including [layout regressions](../../__test__/layout), [providers](../../__test__/app/global-provider.spec.ts), and related hooks. Select affected layout modes using the [browser dimensions](../README.md#browser-verification). Check narrow widths for sizing changes, and reload restoration/readback when cache or preference behavior changes.
