The [focused code review](../../docs/table-pro-review.md) records reproduced issues, remediation batches, and verification limits.

Remote `total` means the count after filtering. Cancellation requires the request function to forward `signal`. When changing instance capabilities, check component exposure, the hook, and public exports together. When editing example parameters, distinguish lightweight documentation examples from [embedded admin examples](docs.md).

Targeted verification: `pnpm harness verify table-pro` covers the table, search, columns, and export. Small fixes to one behavior can run its test file directly. Use the corresponding example to check actual scrolling, downloads, printing, or layout only when that behavior changes; select relevant viewports without traversing every table feature.
