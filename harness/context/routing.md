The [application schema](../../apps/admin/src/router/config/schema.ts) is a re-export. The shared package owns generic validation; the application supplies view loaders, roles, and login state. Keep route names unique. For cached views, check that component names match route names. Frontend menus and guards do not replace server-side authorization.

Targeted verification: `pnpm harness verify routing`. Start with [dynamic configuration](../../__test__/router/config.spec.ts) and [permission regressions](../../__test__/router/permission.spec.ts). For behavior changes, also check menu entry, direct access, reload, and source switching. Consult [layout and state](layout.md) when caching or settings are involved.
