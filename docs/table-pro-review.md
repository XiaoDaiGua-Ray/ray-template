# TablePro code review · 2026-11-05

Baseline: `d15966cf`. Scope: RTablePro, TablePanel, useTablePro, search controls and state, column settings, CSV/printing, styles, public types, and application/documentation examples. The findings below describe the baseline; remediation results are recorded at the end.

P1 means address before further expansion; P2 means a concrete functional or usage limitation; P3 can be handled alongside related work. “Reproduced” below means local Vitest tests reproduced the existing behavior. Other findings are inferred from source.

## P1

1. **Data from the previous query scope remains actionable after switching scopes (reproduced).** [TablePro.tsx](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePro.tsx#L191-L257) starts a query when request, params, or pagination changes, but replaces result only on success. Load `scope=a`, then switch to a failing `scope=b`: the table, total, `getCurrentPageData()`, and export still use A. Preserving results during a same-scope refresh matches the documentation; retaining another scope's results can mislead bulk operations when scope represents an account, tenant, or order. Bind successful results to a query snapshot. At minimum, clear results or disable operations when the business scope or data source changes, while separately preserving old data for same-scope failures.

## P2

2. **Search submission and instance page changes do not take effect with controlled local pagination (reproduced).** [TablePro.tsx](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePro.tsx#L266-L308) writes only its internal page. [Rendering](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePro.tsx#L423-L459) prefers external `pagination.page`, while callbacks run only for paginator actions. With `pagination.page=2`, submitting search still passes 2 to DataTable. Unify controlled updates for user clicks, search resets, and instance operations. Distinguish request mode, manually managed remote mode, and local mode in the documentation.
3. **Changing search rules without changing field type retains the old applied rules (reproduced).** [search.ts](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/search.ts#L218-L231) determines field retention only from type and multiple. [TablePro.tsx](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePro.tsx#L324-L352) treats value compatibility as permission to keep the snapshot. Changing a field's `matches` from always true to always false still leaves old rows visible. Updates to `getValue`, `transform`, or `visible` can also retain old conditions. Separate value compatibility from query-semantic changes; rebuild predicate/params for the latter.
4. **Exceptions in search visibility or matching callbacks bypass the error boundary.** [useTableSearch.ts](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/useTableSearch.ts#L44-L56) normalizes before commit. A throwing `visible` callback rejects the submit Promise (reproduced), and the [template](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/components/Search.tsx#L255-L258) does not handle the rejection. [TablePro.tsx](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePro.tsx#L182-L187) also executes `getValue/matches` in a computed value used by rendering; those exceptions bypass search-error as well. Decide whether callback exceptions are developer errors or recoverable errors. If recoverable, report them and retain the last valid result both during submission and predicate execution.
5. **Local column-value lookup differs from Naive UI and export behavior.** [search.ts](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/search.ts#L289-L291) uses `row[key]`; [CSV](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/csv.ts#L33-L40) and [printing](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/printing.ts#L89-L96) use lodash `get`. With nested data and `key: 'customer.name'`, search cannot find the displayed value; the field currently needs an explicit getValue. Share default lookup semantics while retaining explicit getValue precedence.
6. **Row context-menu callbacks do not receive the triggering row.** [TablePanel.tsx](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePanel.tsx#L149-L168) has row and index but stores only coordinates. [Menu selection](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePanel.tsx#L293-L299) emits only key/option, making row-level editing or deletion unsafe. There is no keyboard equivalent. Include row context in the callback and clear it on close, or explicitly define the feature as a table-level menu.
7. **Custom print regions lose host styles and some live control state.** [printing.ts](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/printing.ts#L103-L116) clones DOM into a [separate iframe](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/printing.ts#L155-L169) containing only print styles. Regions dependent on application CSS, asynchronous fonts, canvas pixels, or non-clonable state can differ from the screen. The documented dedicated `style` option needs explicit limits. Verify reports and cleanup after print cancellation in Chrome/Safari.

## P3

8. **Local search can reduce allocations and repeated computation.** [search.ts](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/search.ts#L294-L330) lowercases search text for every row and uses nested linear searches for multi-select arrays. [Dependencies](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/search.ts#L184-L213) rescan all fields for each changed dependency. Precompute lowercase queries and Sets; add reverse dependency indexes for large field counts if needed. Virtual scrolling limits DOM work, not filtering costs. No large-dataset benchmark was run.
9. **Pagination width causes unnecessary updates, and locale dictionaries are repeatedly shallow-copied.** The ResizeObserver in [TablePanel.tsx](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePanel.tsx#L42-L46) feeds continuously changing width into [rendering](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePanel.tsx#L210-L213); pagination mode only needs to change when crossing 600px. [locale.ts](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/locale.ts#L9-L17) clones the entire dictionary before every translation, even when host translation succeeds. Prebuild fixed dictionaries and prefer host translations. Performance impact was not quantified.
10. **Public prop forwarding boundaries are difficult to verify.** [props.ts](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/props.ts#L6-L23) inherits the full Naive UI set, then splits it in both [TablePro](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePro.tsx#L407-L440) and [TablePanel](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/TablePanel.tsx#L176-L199). New wrapper fields or Naive UI upgrades can expose inapplicable options. Clarify wrapper-controlled fields and add contract cases for controlled pagination, controlled columns, and slots. Name internal `C.tsx` and `Props.tsx` by responsibility to improve discovery.
11. **Column ordering is drag-only, and visibility reset differs from layout reset.** [C.tsx](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/components/C.tsx#L136-L177) supports pointer dragging and keyboard checkbox selection but not keyboard ordering. “Show all” clears only hidden state; [order and fixed-column patches](https://github.com/XiaoDaiGua-Ray/ray-template/blob/d15966cf637fe8bb6d488c45945a56c26b52e158/packages/ui/src/RTablePro/src/columns.ts#L44-L93) remain. For complete reset and keyboard operation, add explicit move-up/down actions and a separate layout reset. Persisting visibility alone matches the current documentation.

## Designs to preserve

Validate `total` and data shape before accepting a successful request. Forward AbortSignal to callers and use it to reject stale results. Keep search drafts separate from applied snapshots and version asynchronous validation. Column visibility must not mutate props directly. Retain CSV formula-prefix protection and default printing through textContent and an isolated iframe.

Four paths marked “reproduced” were independently verified with Vue Test Utils / Vitest. Reproduction tests and output were saved locally as `.harness-local/table-pro-review-repro.local.spec.ts` and `.harness-local/table-pro-review-repro.log`; known defects were not encoded as permanent repository expectations. Real performance, native print dialogs, and screen readers were outside runtime verification scope.
