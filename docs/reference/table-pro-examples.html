TablePro 在线示例 ​

从纯表格开始，按需加入查询、分页、列设置或打印。以下示例使用 Ray Admin 的真实组件和演示数据，无需登录或连接业务接口。展开「运行示例」后才加载交互区域；窄屏可以在表格内横向滚动，也可以在新标签页打开。每个示例都附实际运行的源码。

纯表格与本地排序 ​

点击「年龄」表头，在升序、降序和默认顺序间切换。表格只消费给定的 10 行；bare 隐藏标题和工具栏，并默认关闭分页。宽表通过 scrollX 保留列宽。

运行示例

在新标签页运行此示例

查看纯表格源码
tsx
import { RTablePro } from '@/components'
import { useI18n } from '@/hooks/template/useI18n'
import { createPeopleColumns } from './people'
import { usePeopleData } from './usePeopleData'

export default defineComponent({
  name: 'TableDemoBasic',
  setup() {
    const { t } = useI18n('table')
    const { data, loading } = usePeopleData(() => ({ page: 1, pageSize: 10 }))
    const columns = computed(() =>
      createPeopleColumns(t).map((column) => {
        if ('key' in column && column.key === 'age')
          return {
            ...column,
            sorter: (
              a: (typeof data.value)[number],
              b: (typeof data.value)[number],
            ) => a.age - b.age,
          }

        return column
      }),
    )

    return () => (
      <RTablePro
        bare
        data={data.value}
        loading={loading.value}
        columns={columns.value}
        scrollX={944}
      />
    )
  },
})

远端查询与失败恢复 ​

  1. 复制某行姓名或邮箱的一部分，填入上方筛选区并提交。查询回到第 1 页，分页使用筛选后的总数。
  2. 清除条件后排序「年龄」并翻页。年龄排序通过 onUpdateSorter 转成 params.sortAge，在分页前作用于整个结果集。
  3. 分别在两页勾选行；工具栏显示跨页选中总数。「更多操作 → 导出 CSV」导出当前页可见数据列。
  4. 点击「模拟请求失败」，观察旧行清空和错误提示；点击「刷新」恢复。传给 request 的 signal 可转交给 HTTP 客户端。

查看远端查询源码
tsx
import { getPersonList } from '@/api/demo/mock/person'
import type { PersonListParams } from '@/api/demo/mock/person'
import { RTablePro } from '@/components'
import type { TableProInst } from '@/components'
import { useI18n } from '@/hooks/template/useI18n'
import { NButton, NTag } from 'naive-ui'
import type { DataTableSortState } from 'naive-ui'
import { createPeopleColumns } from './people'

export default defineComponent({
  name: 'TableDemoRemote',
  setup() {
    const { t } = useI18n('table')
    const table = shallowRef<TableProInst>()
    const checked = ref<(string | number)[]>([])
    const columns = computed(() => [
      { type: 'selection' as const, width: 44 },
      ...createPeopleColumns(t).map((column) =>
        'key' in column && column.key === 'age'
          ? { ...column, sorter: true }
          : column,
      ),
    ])
    const params = shallowRef<PersonListParams>({})
    const updateSorter = (
      sorter: DataTableSortState | DataTableSortState[] | null,
    ) => {
      const state = Array.isArray(sorter) ? sorter[0] : sorter

      params.value = {
        sortAge:
          state?.columnKey === 'age' && state.order ? state.order : void 0,
      }
    }
    let failNext = false
    const request: typeof getPersonList = (params, signal) => {
      if (failNext) {
        failNext = false

        return Promise.reject(new Error(t('demoFailure')))
      }

      return getPersonList(params, signal)
    }

    return () => (
      <RTablePro
        ref={table}
        title={t('directory')}
        columns={columns.value}
        v-model:checkedRowKeys={checked.value}
        allowCheckingNotLoaded
        request={request}
        params={params.value}
        onUpdateSorter={updateSorter}
        columnStateKey="demo:remote"
        search={[
          { key: 'name', label: t('name'), placeholder: t('nameHint') },
          { key: 'email', label: t('email'), placeholder: t('emailHint') },
        ]}
        scrollX={944}
        downloadCsvTableOptions={{ fileName: 'people' }}
      >
        {{
          toolbar: () => (
            <>
              <NTag size="small" bordered={false} type="info">
                {t('httpSource')}
              </NTag>
              {checked.value.length ? (
                <NButton
                  text
                  onClick={() => {
                    checked.value = []
                  }}
                >
                  {t('clearSelection', { count: checked.value.length })}
                </NButton>
              ) : null}
              <NButton
                size="small"
                quaternary
                onClick={() => {
                  failNext = true
                  void table.value?.reload()
                }}
              >
                {t('demoFailure')}
              </NButton>
            </>
          ),
        }}
      </RTablePro>
    )
  },
})

手动远端分页 ​

此例用本地数据模拟外部接口，只向表格传入当前页。先翻到第 2 页，再按姓名筛选；页码会回到第 1 页，总数随条件更新。改变每页条数也会回到第 1 页。

页面拥有 page、pageSize 和 itemCount，通过分页回调与 onSearch 更新。接入异步服务时，在这一层维护加载、取消和错误；希望由 TablePro 管理这些状态时，使用上一个示例的 request。

运行示例

在新标签页运行此示例

查看受控分页源码
tsx
import { useI18n } from '@/hooks/template/useI18n'
import { RTablePro } from '@ray-template/ui/table-pro'
import { createPeopleColumns } from './people'
import { usePeopleData } from './usePeopleData'

export default defineComponent({
  name: 'TableDemoControlled',
  setup() {
    const { t } = useI18n()
    const page = ref(1)
    const pageSize = ref(10)
    const name = ref<string>()
    const { data, total, loading } = usePeopleData(() => ({
      page: page.value,
      pageSize: pageSize.value,
      name: name.value,
    }))
    const columns = computed(() =>
      createPeopleColumns((key) => t(`table.${key}`)),
    )

    return () => (
      <RTablePro
        title={t('menu.TableControlled')}
        remote
        data={data.value}
        loading={loading.value}
        columns={columns.value}
        scrollX={944}
        pagination={{
          page: page.value,
          pageSize: pageSize.value,
          itemCount: total.value,
          showSizePicker: true,
          pageSizes: [10, 20, 50],
          onUpdatePage: (value) => (page.value = value),
          onUpdatePageSize: (value) => {
            pageSize.value = value
            page.value = 1
          },
        }}
        search={{
          fields: [{ key: 'name', label: t('table.name'), type: 'text' }],
        }}
        onSearch={({ values }) => {
          name.value = typeof values.name === 'string' ? values.name : void 0
          page.value = 1
        }}
      />
    )
  },
})

高级搜索 ​

此例可在本地匹配和模拟远端之间切换。每次操作后比较下方的「草稿」「已应用条件」「转换后的参数」和「实际列表请求」：

  1. 组合条件：添加状态多选和创建日期区间后提交。远端请求中的日期会拆成 createdFrom 和 createdTo，翻页继续沿用这些条件。
  2. 联动和取消：快速切换北区和南区。负责人草稿会清空，旧的候选请求会取消。在南区候选项中搜索「王雨」。
  3. 零值与布尔值：点击「交付与金额」，应用条件后展开订单。查看商品级联、仓库树、配送控件和日期时间字段如何配合，确认参数保留 minAmount: 0 与 invoiced: false。
  4. 校验与自动查询：提交单字符关键词，确认旧结果仍在；修正输入后切换为输入后自动应用，连续编辑观察防抖。
  5. 分别恢复失败：让负责人候选或列表失败一次。候选可在字段处重试，列表可再次提交。

      const id = ++requestId

          entry.id === id ? { ...entry, phase } : entry,
        )
      }

      try {
        signal.throwIfAborted()
        const value = await result()

        signal.throwIfAborted()

        finish('success')

        return value
      } catch (error) {
        finish(signal.aborted ? 'cancelled' : 'failed')
        throw error
      }

export function orderMatchesQuery(row: DemoOrder, query: DemoOrderQuery) {
  const {
    keyword,
    status,
    createdFrom,
    createdTo,
    orgId,
    ownerId,
    productId,
    warehouseId,
    minAmount,
    invoiced,
    delivery,
    deliveryFrom,
    deliveryTo,
    deliveryTime,
  } = query

  return (
    `${row.orderNo} ${row.product}`
      .toLowerCase()
      .includes(String(keyword ?? '').toLowerCase()) &&
    (!status?.length || status.includes(row.status)) &&
    (typeof createdFrom !== 'string' || row.createdAt >= createdFrom) &&
    (typeof createdTo !== 'string' || row.createdAt <= createdTo) &&
    (orgId == null || row.orgId === orgId) &&
    (ownerId == null || row.ownerId === ownerId) &&
    (productId == null || row.productId === productId) &&
    (warehouseId == null || row.warehouseId === warehouseId) &&
    (typeof minAmount !== 'number' || row.amount >= minAmount) &&
    (invoiced == null || row.invoiced === invoiced) &&
    (delivery == null || row.delivery === delivery) &&
    (typeof deliveryFrom !== 'number' || row.deliveryAt >= deliveryFrom) &&
    (typeof deliveryTo !== 'number' || row.deliveryAt <= deliveryTo) &&
    (deliveryTime == null || row.deliveryTime === deliveryTime)
  )
}

先切到第 2 页，再比较「刷新当前页」和「回首页并刷新」。使用模拟失败按钮观察 queryState 的加载、失败和总数变化，并用刷新恢复。提交姓名条件后，示例会显示实际发出的参数。快速切换页码可以观察最新请求的结果。

查看查询 Hook 源码
tsx
import { apiMockEnabled } from '@/api/admin/client'
import { getPersonList } from '@/api/demo/mock/person'
import type { PersonListParams } from '@/api/demo/mock/person'
import { RTablePro, useTablePro } from '@/components'
import { useI18n } from '@/hooks/template/useI18n'
import {
  NButton,
  NCard,
  NFlex,
  NInput,
  NStatistic,
  NTag,
  NText,
} from 'naive-ui'
import { useId } from 'vue'
import DemoPage from '../components/DemoPage'
import { createPeopleColumns } from './people'

const statusColors = {
  idle: 'default',
  loading: 'info',
  failed: 'error',
  loaded: 'success',
} as const

export default defineComponent({
  name: 'TableDemoHooksQuery',
  setup() {
    const { t } = useI18n()
    const [register, { isReady, queryState, reload, setPage, setPageSize }] =
      useTablePro()
    const inputId = useId()
    const nameDraft = ref('')
    const params = shallowRef<PersonListParams>({})
    const lastRequest = shallowRef<PersonListParams>({})
    const attempts = ref(0)
    const columns = computed(() =>
      createPeopleColumns((key) => t(`table.${key}`)).slice(0, 4),
    )
    const phase = computed(() => {
      if (queryState.value?.loading) return 'loading'

      if (queryState.value?.failed) return 'failed'

      return queryState.value?.total != null ? 'loaded' : 'idle'
    })

    let failNext = false
    const request = async (query: PersonListParams, signal: AbortSignal) => {
      const shouldFail = failNext

      failNext = false
      attempts.value += 1
      lastRequest.value = query

      return getPersonList({ ...query, fail: shouldFail }, signal)
    }

    const applyName = (value: string) => {
      if (!isReady.value) return

      const name = value.trim() || void 0

      if (name === params.value.name) {
        void reload(true)
      } else {
        // params 变化已经会回到第一页请求，避免再手动刷新一次。
        params.value = { name }
      }
    }

    return () => (
      <DemoPage
        title={t('menu.TableHooksQuery')}
        description={t('tableHooks.queryDescription')}
      >
        <NCard>
          <NFlex vertical>
            <form
              class="r-table-search"
              onSubmit={(event) => {
                event.preventDefault()
                applyName(nameDraft.value)
              }}
            >
              <div class="r-table-search__field">
                <label for={inputId}>{t('table.name')}</label>
                <NInput
                  inputProps={{ id: inputId, name: 'name' }}
                  v-model:value={nameDraft.value}
                  placeholder={t('table.nameHint')}
                />
              </div>
              <div class="r-table-search__actions">
                <NButton
                  attrType="submit"
                  type="primary"
                  disabled={!isReady.value}
                >
                  {t('table.search')}
                </NButton>
                <NButton
                  disabled={!isReady.value}
                  onClick={() => {
                    nameDraft.value = ''
                    applyName('')
                  }}
                >
                  {t('table.reset')}
                </NButton>
              </div>
            </form>
            <NFlex>
              <NButton disabled={!isReady.value} onClick={() => reload()}>
                {t('tableHooks.reloadPage')}
              </NButton>
              <NButton disabled={!isReady.value} onClick={() => reload(true)}>
                {t('tableHooks.reloadFirstPage')}
              </NButton>
              <NButton disabled={!isReady.value} onClick={() => setPage(2)}>
                {t('tableHooks.secondPage')}
              </NButton>
              <NButton
                disabled={!isReady.value}
                onClick={() => setPageSize(20)}
              >
                {t('table.twentyRows')}
              </NButton>
              {apiMockEnabled && (
                <NButton
                  disabled={!isReady.value || queryState.value?.loading}
                  onClick={() => {
                    failNext = true
                    void reload()
                  }}
                >
                  {t('table.demoFailure')}
                </NButton>
              )}
            </NFlex>
          </NFlex>
        </NCard>
        <NCard title={t('tableHooks.queryStatus')}>
          {{
            'header-extra': () => (
              <NTag
                size="small"
                type={statusColors[phase.value]}
                bordered={false}
              >
                {t(`tableHooks.queryPhase.${phase.value}`)}
              </NTag>
            ),
            default: () => (
              <NFlex vertical size={12}>
                <NFlex size={[24, 12]}>
                  <NStatistic
                    tabularNums
                    label={t('tableHooks.currentPage')}
                    value={queryState.value?.page ?? '—'}
                  />
                  <NStatistic
                    tabularNums
                    label={t('tableHooks.rowsPerPage')}
                    value={queryState.value?.pageSize ?? '—'}
                  />
                  <NStatistic
                    tabularNums
                    label={t('tableHooks.resultTotal')}
                    value={queryState.value?.total ?? '—'}
                  />
                </NFlex>
                <NText depth={3}>
                  {t('tableHooks.lastRequest')}
                  {' · '}
                  {t('tableHooks.requestDetails', {
                    count: attempts.value,
                    page: lastRequest.value.page ?? '—',
                    size: lastRequest.value.pageSize ?? '—',
                    name: lastRequest.value.name ?? '—',
                  })}
                </NText>
              </NFlex>
            ),
          }}
        </NCard>
        <RTablePro
          onRegister={register}
          title={t('table.directory')}
          columns={columns.value}
          request={request}
          params={params.value}
          scrollX={562}
        />
      </DemoPage>
    )
  },
})

跨页选择与批量操作 ​

在两页分别点「选中本页」，再点「取消本页选择」。只有该页的 key 会被移除；对其余行批量标记后，返回相应页面核对结果。排序后点「清除排序」，查看如何调用 getTableInstance() 暴露的底层方法。

查看选择 Hook 源码
tsx
import { RTablePro, useTablePro } from '@/components'
import { useI18n } from '@/hooks/template/useI18n'
import type { Person } from '@ray-template/api-contracts/demo'
import { NButton, NFlex } from 'naive-ui'
import type { DataTableColumns } from 'naive-ui'
import DemoPage from '../components/DemoPage'
import DemoResult from '../components/DemoResult'
import { createPeopleColumns } from './people'
import { usePeopleData } from './usePeopleData'

export default defineComponent({
  name: 'TableDemoHooksSelection',
  setup() {
    const { t } = useI18n()
    const [register, { isReady, getCurrentPageData, getTableInstance }] =
      useTablePro()
    const { data, loading } = usePeopleData()
    const checked = ref<(string | number)[]>([])
    const marked = shallowRef(new Set<string | number>())
    const columns = computed<DataTableColumns<Person>>(() => [
      { type: 'selection', width: 44 },
      ...createPeopleColumns((key) => t(`table.${key}`))
        .slice(0, 4)
        .map((column) =>
          'key' in column && column.key === 'age'
            ? {
                ...column,
                sorter: (left: Person, right: Person) => left.age - right.age,
              }
            : column,
        ),
      {
        title: t('tableHooks.markColumn'),
        key: 'marked',
        width: 110,
        render: ({ id }) =>
          t(marked.value.has(id) ? 'tableHooks.marked' : 'tableHooks.unmarked'),
      },
    ])

    const currentKeys = () =>
      getCurrentPageData()
        .map((row) => row.id)
        .filter((id): id is string => typeof id === 'string')

    const selectPage = () => {
      checked.value = [...new Set([...checked.value, ...currentKeys()])]
    }
    const unselectPage = () => {
      const pageKeys = new Set<string | number>(currentKeys())

      checked.value = checked.value.filter((id) => !pageKeys.has(id))
    }
    const markSelected = () => {
      marked.value = new Set([...marked.value, ...checked.value])
      checked.value = []
    }

    return () => (
      <DemoPage
        title={t('menu.TableHooksSelection')}
        description={t('tableHooks.selectionDescription')}
      >
        <NFlex>
          <NButton
            type="primary"
            disabled={!isReady.value}
            onClick={selectPage}
          >
            {t('tableHooks.selectPage')}
          </NButton>
          <NButton
            disabled={!isReady.value || !checked.value.length}
            onClick={unselectPage}
          >
            {t('tableHooks.unselectPage')}
          </NButton>
          <NButton
            disabled={!checked.value.length}
            onClick={() => {
              checked.value = []
            }}
          >
            {t('tableHooks.clearAll')}
          </NButton>
          <NButton disabled={!checked.value.length} onClick={markSelected}>
            {t('tableHooks.markSelected')}
          </NButton>
          <NButton
            disabled={!isReady.value}
            onClick={() => getTableInstance()?.clearSorter()}
          >
            {t('tableHooks.clearSort')}
          </NButton>
        </NFlex>
        <DemoResult label={t('tableHooks.selectionResult')}>
          {t('tableHooks.selectionDetails', {
            selected: checked.value.length,
            marked: marked.value.size,
          })}
        </DemoResult>
        <RTablePro
          onRegister={register}
          title={t('table.directory')}
          columns={columns.value}
          data={data.value}
          loading={loading.value}
          v-model:checkedRowKeys={checked.value}
          search={[
            {
              key: 'name',
              label: t('table.name'),
              placeholder: t('table.nameHint'),
            },
          ]}
          scrollX={716}
        />
      </DemoPage>
    )
  },
})

导出与打印的实例生命周期 ​

下载「导出当前页 CSV」和「导出全部已加载数据 CSV」并比较行数。前者只包含当前页，后者使用 keepOriginalData 导出传入表格的整批数据；远端模式下它不会自动请求其他页。点击卸载后观察操作按钮禁用，重新挂载会再次注册实例。

运行示例

在新标签页运行此示例

查看输出 Hook 源码
tsx
import { RTablePro, useTablePro } from '@/components'
import { useI18n } from '@/hooks/template/useI18n'
import { NButton, NFlex } from 'naive-ui'
import DemoPage from '../components/DemoPage'
import DemoResult from '../components/DemoResult'
import { createPeopleColumns } from './people'
import { usePeopleData } from './usePeopleData'

export default defineComponent({
  name: 'TableDemoHooksOutput',
  setup() {
    const { t } = useI18n()
    const [register, { isReady, downloadCsv, print }] = useTablePro()
    const { data, loading } = usePeopleData()
    const mounted = ref(true)
    const printResult = ref<boolean>()
    const columns = computed(() =>
      createPeopleColumns((key) => t(`table.${key}`)).slice(0, 4),
    )

    return () => (
      <DemoPage
        title={t('menu.TableHooksOutput')}
        description={t('tableHooks.outputDescription')}
      >
        <NFlex>
          <NButton
            onClick={() => {
              mounted.value = !mounted.value
              printResult.value = void 0
            }}
          >
            {t(mounted.value ? 'tableHooks.unmount' : 'tableHooks.mount')}
          </NButton>
          <NButton
            disabled={!isReady.value}
            onClick={() => downloadCsv({ fileName: 'people-page' })}
          >
            {t('tableHooks.csvPage')}
          </NButton>
          <NButton
            disabled={!isReady.value}
            onClick={() =>
              downloadCsv({ fileName: 'people-loaded', keepOriginalData: true })
            }
          >
            {t('tableHooks.csvLoaded')}
          </NButton>
          <NButton
            disabled={!isReady.value}
            onClick={async () => {
              printResult.value = await print({
                title: t('table.printDemoTitle'),
              })
            }}
          >
            {t('table.printDemoTitle')}
          </NButton>
        </NFlex>
        <DemoResult
          label={t('tableHooks.mountStatus')}
          error={printResult.value === false}
        >
          {t(isReady.value ? 'tableHooks.ready' : 'tableHooks.notReady')}
          {printResult.value === void 0 ? null : (
            <div>
              {t(
                printResult.value
                  ? 'tableHooks.printOpened'
                  : 'table.printError',
              )}
            </div>
          )}
        </DemoResult>
        {mounted.value ? (
          <RTablePro
            onRegister={register}
            title={t('table.directory')}
            columns={columns.value}
            data={data.value}
            loading={loading.value}
            search={[
              {
                key: 'name',
                label: t('table.name'),
                placeholder: t('table.nameHint'),
              },
            ]}
            columnStateKey="demo:hooks-output"
            scrollX={562}
          />
        ) : null}
      </DemoPage>
    )
  },
})
