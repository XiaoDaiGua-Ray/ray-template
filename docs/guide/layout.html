应用布局与状态 ​

打开「布局实验室」或顶部设置抽屉里的「布局」页签，切换导航和工作区。桌面支持侧边 side、顶部 top、混合 mixed、右侧 right 和通栏分组 split 导航；混合模式把一级导航放在顶部，侧栏只显示当前分组的子菜单。宽度不超过 768px 时改用抽屉，保留原桌面偏好。

在线布局实验 ​

在预览中切换导航方向、固定顶栏或内容宽度。预览使用 Ray Admin 的布局与设置组件，菜单和状态只在当前示例里生效。

查看示例源码
vue
<template>
  <DemoFrame :dark="dark" :locale="locale">
    <div
      class="shell-demo"
      :class="{ 'r-template--dark': dark }"
      :lang="locale"
    >
      <AdminShell :layout="layout" :groupedSidebar="true" showTabs showFooter>
        <template #header>
          <div class="shell-bar">
            <strong>Ray Admin</strong>
            <NButton size="small" @click="dark = !dark">{{
              dark ? copy.light : copy.dark
            }}</NButton>
          </div>
          <ShellTopNavigation
            v-if="['top', 'mixed', 'split'].includes(layout.mode)"
            :items="menu"
            :active="active"
            :grouped="layout.mode !== 'top'"
            :label="copy.navigation"
            :select="(item) => navigate(item.fullPath)"
          />
        </template>
        <template #sidebar>
          <NLayoutSider :width="132" bordered>
            <NMenu :options="menu" :value="active" @update:value="navigate" />
          </NLayoutSider>
        </template>
        <template #tabs>
          <div class="shell-bar">
            <ShellTab
              v-for="item in pages"
              :key="item.path"
              :label="item.label"
              :active="active === item.path"
              :select="() => navigate(item.path)"
            />
          </div>
        </template>
        <h2>{{ title }}</h2>
        <LayoutSettings
          :layout="layout"
          :defaults="defaults"
          :translate="translate"
          :update="updateLayout"
        />
        <template #footer>
          <div class="shell-bar">{{ copy.footer }}</div>
        </template>
      </AdminShell>
    </div>
  </DemoFrame>
</template>

<script setup lang="ts">
import {
  AdminShell,
  LayoutSettings,
  ShellTab,
  ShellTopNavigation,
} from '@ray-template/admin-shell'
import type { LayoutConfig } from '@ray-template/admin-shell'
import { NButton, NLayoutSider, NMenu } from 'naive-ui'
import { computed, onMounted, ref } from 'vue'
import { createMemoryHistory, createRouter } from 'vue-router'
import DemoFrame from './DemoFrame.vue'

const props = withDefaults(defineProps<{ locale?: 'zh-CN' | 'en' }>(), {
  locale: 'zh-CN',
})
const copy = computed(() =>
  props.locale === 'en'
    ? {
        dashboard: 'Dashboard',
        reports: 'Reports',
        navigation: 'Navigation',
        light: 'Light theme',
        dark: 'Dark theme',
        footer: 'Layout preview',
        settings: 'Layout',
        side: 'Left',
        top: 'Top',
        mixed: 'Mixed',
        right: 'Right',
        split: 'Split',
        contentWidth: 'Content width',
        fluid: 'Fluid',
        fixed: 'Fixed',
        maxWidth: 'Maximum width',
        padding: 'Padding',
        fixedHeader: 'Fixed header',
        fixedFooter: 'Fixed footer',
        reset: 'Reset layout',
      }
    : {
        dashboard: '工作台',
        reports: '报表',
        navigation: '导航',
        light: '浅色主题',
        dark: '深色主题',
        footer: '布局预览',
        settings: '布局',
        side: '侧边导航',
        top: '顶部导航',
        mixed: '混合导航',
        right: '右侧导航',
        split: '通栏分组',
        contentWidth: '内容宽度',
        fluid: '流式铺满',
        fixed: '定宽居中',
        maxWidth: '最大宽度',
        padding: '内容间距',
        fixedHeader: '固定顶栏',
        fixedFooter: '固定页脚',
        reset: '恢复默认布局',
      },
)
const translate = (key: string) =>
  copy.value[(key === 'tab' ? 'settings' : key) as keyof typeof copy.value] ??
  key
const defaults: LayoutConfig = {
  mode: 'side',
  contentWidth: 'fluid',
  contentMaxWidth: 1200,
  contentPadding: 16,
  fixedHeader: true,
  fixedFooter: true,
}
const layout = ref({ ...defaults })
const updateLayout = (patch: Partial<LayoutConfig>) => {
  layout.value = { ...layout.value, ...patch }
}
const dark = ref(false)
const pages = computed(() => [
  { path: '/', label: copy.value.dashboard },
  { path: '/reports', label: copy.value.reports },
])
const router = createRouter({
  history: createMemoryHistory(),
  routes: pages.value.map(({ path }) => ({
    path,
    component: { render: () => null },
  })),
})
const active = computed(() => router.currentRoute.value.path)
const title = computed(
  () => pages.value.find(({ path }) => path === active.value)?.label,
)
const menu = computed(() =>
  pages.value.map(({ path, label }) => ({
    key: path,
    label,
    path,
    fullPath: path,
    name: path,
    meta: {},
  })),
)
const navigate = (path: string) => {
  void router.push(path)
}

onMounted(() => navigate('/'))
</script>

配置工作区 ​

ts
import { useSettingActions } from '@/store'

const { updateSettingState } = useSettingActions()

updateSettingState('layoutConfig', {
  mode: 'mixed',
  contentWidth: 'fixed',
  contentMaxWidth: 1200,
  contentPadding: 16,
})

最大宽度范围是 640–2560px，间距为 0–48px。顶栏和页脚可固定或随内容滚动。旧设置补齐默认值，布局恢复默认只重置 layoutConfig。

替换布局区域 ​

RLayout 提供 header、sidebar、tabs、footer 和 default 插槽。模式和显隐开关仍生效，例如顶部导航模式不会渲染侧栏。替换 default 内容时，需要自行接入所需的路由缓存和请求取消。

状态放在哪里 ​

状态入口刷新后的行为
加载、移动抽屉、内容最大化、重载useRuntimeGetters / useRuntimeActions运行态，不持久化
布局、主题、语言等偏好useSettingGetters / useSettingActions沿用设置缓存；旧值补默认配置
锁屏锁屏 Store保留历史布尔值格式和跨标签同步

新增共享状态按职责放到 apps/admin/src/store/modules，对外用 Store hooks。持久化使用 pick / omit 选择字段；检查历史 key 和序列化格式再变更。

布局说明与插槽 · 状态实现与持久化

更细的状态字段与更新动作见 Setting Store、Runtime Store 和 布局 Hooks。
