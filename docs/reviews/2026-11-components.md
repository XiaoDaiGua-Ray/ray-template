# Component implementation review — 2026-11-06

## Scope and acceptance

This review follows the application compatibility exports into all twelve shared `R*` component implementations, the application route-transition adapter, and the app-bound wrappers/providers. It includes component-local hooks, utilities, props, slots, instance APIs, existing tests, and their admin/documentation consumers. Theme palettes and startup/content loading are tracked in the separate UI review. Generic composables and utilities have a separate review.

The acceptance criteria are correct controlled state, preserved native configuration and callbacks, explicit resource ownership, bounded reactive work, accessible default controls, accurate public contracts, and regression coverage for the defects found. No throughput or browser memory improvement is claimed without a benchmark.

## TablePro toolbar

Business toolbar content and built-in utilities are separate visual groups. Request-managed tables expose refresh directly; column settings and fullscreen remain direct controls. A single More actions menu contains density, striped/bordered toggles and CSV. Printing is absent by default and appears only with `showPrint`. The explicit instance `print()` method remains available regardless of menu visibility.

This removes two always-mounted popselect wrappers while preserving their functions. Existing `tool={false}`, `bare`, toolbar slots, request callbacks, CSV formatting/default options, and printing options remain supported. The printing demo opts in; the remote demo uses the built-in refresh/export entries instead of duplicate buttons. Both locales and public references were updated.

The method audit covered `useChart` and its registration/access/dispose/render methods, `useChartProvider`, `useForm` and its model/rules/validation/reset/update methods, `useFlow`, deprecated `useModal.create`, `useTablePro`, `useTableRequest`, `useTableSearch`, column layout/visibility, search value/parameter/predicate helpers, pagination forwarding, CSV construction/download, printable-content construction and printing, locale resolution, prop selection, and injected UI services. Public helpers now have adjacent multiline contracts using actual parameter names and ordered tags. Interface method properties use short property documentation; private trivial event lambdas remain covered by their owning contract instead of duplicating line-by-line explanations.

## Verification

Later browser validation found that group pinning updated header offsets but not body-cell fixed classes in the installed Naive UI implementation. Group pin/unpin now applies `fixed` recursively to descendants in both local and controlled layout paths, without mutating source definitions or cascading unrelated properties. The focused columns suite passed 9 tests, including both ownership modes and actual native fixed-cell classes.

The follow-up removes deprecated pagination callback aliases from the public TablePro pagination contract and strips them from untyped runtime input. Current update events remain supported. The default toolbar also gains PNG clipboard copying through the existing lazy DOM renderer. Capture is restricted to the native table's visible DOM box, with temporary scroll/sticky snapshots, user-activation-safe promised clipboard data, local/host feedback and cancellation cleanup. This is distinct from full-page data export; virtualized unmounted rows are not synthesized.

The follow-up's affected table regression set passed 7 files / 63 tests. After the final loading/cancellation adjustment, the image regression file passed all 10 cases; `vue-tsc --build`, touched-file ESLint/Prettier checks, and `git diff --check` passed. Actual native clipboard/paste fidelity is part of the lead's Chrome acceptance, not established by mocked clipboard unit tests.

Chrome acceptance subsequently reproduced missing external RIcon sprites in PNG output. A focused, private SVG preparation helper now expands registered/same-origin public sprites and local symbols into isolated static vectors before rendering, with per-capture fetch deduplication, anonymous non-redirecting requests, bounded input and cancellation. Static attributes/currentColor/viewBox are retained; imported IDs and handlers are omitted, and resource-dependent or active SVG content is rejected. The connected table snapshot also removes scripts/event attributes and rejects active embedded media before cloning. The two focused image suites passed 29 tests; native sprite fidelity is rechecked by the lead.

Focused regression coverage includes component wrappers, barcode redraw, flow initialization/readonly/lifecycle, drag cleanup, nested column visibility, toolbar defaults/options/actions, and app-wrapper/clock lifecycle. Existing chart, table search/query/export and modal suites are included in the combined component run.

Executed: `pnpm test:run __test__/components __test__/app/wrapper-lifecycle.spec.tsx` passed 14 files / 109 tests. ESLint with `--max-warnings=0`, Prettier checks for all files owned by this review, and `git diff --check` passed. The final workspace type/build check belongs to the lead's integration pass; the scoped work emitted no component type errors.

The lead agent records the final integrated type/lint/format/build results and actual Chrome observations. Unit tests with mocked ECharts, LogicFlow or Interact.js establish wrapper contracts, not canvas-rendering fidelity, pointer gesture physics or browser print output. Scanning a physical barcode, arbitrary third-party iframe policies, and browser-specific printer output are outside this local audit.
