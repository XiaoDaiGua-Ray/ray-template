# API Reference {#api-参考}

The reference is organized by public entry point. Follow the [first-page guide](../guide/first-page) before building a page, and use the sections below to look up individual APIs.

| Area                                         | Covers                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------ |
| [Components](./components)                   | Shared components, props, events, slots, instance methods, and providers |
| [Hooks](./hooks)                             | Navigation, state, pagination, browser APIs, and side effects            |
| [Directives](./directives)                   | Binding values, modifiers, updates, and teardown                         |
| [Stores](./store)                            | State, getters, actions, and persistence                                 |
| [Utilities](./utils)                         | Types, numbers, DOM, files, and storage                                  |
| [SVG icons](./icons)                         | Icon paths, type generation, and `RIcon`                                 |
| [Application configuration](./configuration) | Themes, routes, localization, requests, and builds                       |

Use the [source version listed for this site](./source). Examples assume the Ray Template `@` alias and default application context.
