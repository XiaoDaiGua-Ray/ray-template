# API 参考

这里按调用入口组织。首次开发页面可以从[开发指南](../guide/first-page)走一遍，查具体 API 时从下列索引进入。

| 领域                        | 内容                                            |
| --------------------------- | ----------------------------------------------- |
| [组件](./components)        | 通用组件、属性、事件、插槽、实例方法和 Provider |
| [Hooks](./hooks)            | 导航、状态、分页、浏览器能力及副作用边界        |
| [指令](./directives)        | 绑定值、修饰符、更新和卸载规则                  |
| [Store](./store)            | 状态字段、Getter、Action 和持久化契约           |
| [工具函数](./utils)         | 类型、数值、DOM、文件和缓存                     |
| [SVG 图标](./icons)         | 图标路径、类型生成和 `RIcon`                    |
| [应用配置](./configuration) | 主题、路由、国际化、请求和构建入口              |

各页以[文档标明的源码版本](./source)为准。示例假设已在 Ray Template 项目中使用 `@` 别名和默认应用上下文。
