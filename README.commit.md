# Commit conventions

## Commit message format

Use the following `commit message` types:

- feat: New feature
- fix: Bug fix
- update: Code update
- docs: Documentation
- style: Formatting changes that do not affect runtime behavior
- refactor: Code restructuring that neither adds a feature nor fixes a bug
- test: Additional tests
- chore: Changes to the build process or supporting tools
- revert: Revert a change
- merge: Merge branches
- perf: Optimization, such as performance or user experience improvements
- build: Build changes
- plugin: Plugin updates
- publish: Publication

Customize the `commit message` format in `commitlint.config.cjs` when needed.
